### `ios/Apex/AppModel.swift`
- [ ] **P1** · *Functions — do one thing (G30) / Names — misleading (N1)* · `ios/Apex/AppModel.swift:170` — `ensureQueue(owner:email:)` is 137 lines (170–307). It handles the owner-switch teardown, builds the write queue, sets the cache owner, sweeps bootstraps, sets up the Live Activity (APNs environment, adopt, endFinished hook), and builds Health, TrackerServices, the queue driver, coach, meals, You (with a nested LibraryDependencies), onboarding, the realtime observer and the terms check. The name mentions only the queue, so a reader looking for "where the coach is built" will not find it. **Fix:** rename to `activateAccount(owner:email:)`. Extract `makeActivityPublisher(client:cache:)`, `makeCoach(client:owner:)`, `makeMeals(client:cache:queue:)`, `makeYou(client:cache:email:health:meals:)` and `makeOnboarding(client:)`, so the body reads as one list of steps at a single level of abstraction.
- [ ] **P1** · *Hidden temporal coupling (G31) / Classes — cohesion* · `ios/Apex/AppModel.swift:612` — Per-account state lives in nine separate optionals: `trackerServices` 35, `coach` 38, `coachServices` 40, `you` 43, `meals` 45, `onboarding` 48, `queueOwner` 51, `queueDriver` 58 and `activity` 78. `ensureQueue` builds them and `tearDown` nils them one at a time. The two lists must stay in sync by hand, and they already differ: `tearDown` never clears `activity`, and line 638 re-attaches `trackerServices?.queue` after line 618 has set `trackerServices = nil`, so that call always passes nil. **Fix:** introduce an `AccountSession` type that owns every per-account model, built by one factory and torn down by one `shutdown() async`. AppModel then holds `private(set) var session: AccountSession?`, and teardown becomes `await session?.shutdown(); session = nil`.
- [ ] **P1** · *Switch better as polymorphism (G23) / Duplication (G5)* · `ios/Apex/AppModel.swift:368` — Mock and real auth are told apart by repeated `guard let auth else { mockState = … }` branches: `signIn` 368, `setPassword` 475, `signOut` 598, `open` 431–439, `state` 365, and the separate `openInMock` 517. The fixture identity `"ios-fixture-user"` / `"agent@apex.local"` is retyped at 369, 476, 520 and 524 (and again in MockEnvironment.swift 317 and 565). **Fix:** define an `AuthBackend` protocol (`state`, `signIn`, `signOut`, `setPassword`, `handle(link:url:)`, `sendPasswordReset`). `AuthService` conforms, and a DEBUG `MockAuthBackend` in `ios/Apex/Mock/` holds `mockState` and one `FixtureUser` constant. AppModel then calls the backend with no `nil` checks.
- [ ] **P1** · *Error handling — swallowed errors* · `ios/Apex/AppModel.swift:350` — `purgeDeviceData` runs `try? await store.deleteAll()` during account deletion, and `tearDown` runs `for kind in CacheKind.allCases { try? await cache?.purge(kind: kind) }` at 634 on owner change. Both exist to guarantee another user's data is gone. If either fails, the data stays and nothing is logged. **Fix:** replace with `do/catch` that logs through `Logger(… category: "persistence")`. In `accountDeleted`, also post a failure toast so the user knows coach history may remain on the device.
- [ ] **P2** · *Duplication (G5) / Vague intent (G16)* · `ios/Apex/AppModel.swift:357` — The block `do { try await …; return nil } catch { return Self.readable(error) }` appears in `changePassword` 357–362, `signIn` 372–377, `sendPasswordReset` 383–388, `setPassword` 479–483 and `acceptUpdatedTerms` 577–582. In all of them a `String?` return means "nil = success", which the signature does not say. **Fix:** add `private func failureMessage(_ work: () async throws -> Void) async -> String?`, or return `Result<Void, UserFacingError>`, and use it in each of these functions.
- [ ] **P2** · *Functions — do one thing (G30)* · `ios/Apex/AppModel.swift:407` — `open(_:)` is about 60 lines with a nested switch. It handles three unrelated link families: auth links (with the session-fixation guard and outcome handling), app routes, and connector callbacks. **Fix:** extract `handleAuthLink(_:url:) async` and `handleConnectorLink(_:) async`, leaving `open` as parse, park-or-dispatch.
- [ ] **P2** · *Magic strings (G25) / Duplication (G5)* · `ios/Apex/AppModel.swift:205` — Launch flags are string literals spread across files: `"-apexUITest"` (205, 681), `"-apexAllowAuthLinkWhileSignedIn"` 401, `"-apexMockHealth"` 681, `"-apexMockClient"` (ApexApp.swift:19), `"-apexFrameLog"` (Mock/FrameLog.swift:31), and five `-apexMock*` flags (Mock/MockEnvironment.swift:56–67). - [ ] **P3** · *Inconsistency (G11)* · `ios/Apex/AppModel.swift:126` — `init(auth:)` stores `self.clock = SystemClock()` (line 100) but passes new `SystemClock()` instances to `makeSchedule` 126 and `makeAnalytics` 127, and `ensureQueue` creates another at 203. **Fix:** pass `clock` in each place.
