- [ ] **P1** · *Classes — SRP / cohesion* · `Schedule/ScheduleModel.swift:284` — `ScheduleModel` (848 lines plus `ScheduleModel+Edits.swift`) owns six concerns: the window fetch/cache, outbox-lane bookkeeping (11 published counters at 290–321 plus `attach`, `reloadOutbox`, `letGoStalled`, `retireRefused`, `keepsTrying`, `completionFailed`, `draftFailed`), completion toggling, the meals month cache, stream memoisation and tracker prefetch.
